# 기숙사 봉사활동 · 캠페인 신청 시스템 v1.1

태하관(남) · 서현관(여) **공통** — 학생이 카톡 링크로 직접 신청하고, 선생님은 한 화면에서 취합·출석 체크·엑셀 출력까지 합니다.

```
[학생 휴대폰]  카톡 링크 → 신청           ┐
                                          ├→ [Google 스프레드시트] 자동 취합
[선생님 태블릿] 관리자 화면 → 취합·출석   ┘
```

---

## 📦 들어 있는 파일

| 파일 | 하는 일 |
|------|---------|
| `Code.gs` | **서버**. 구글 스프레드시트에 붙여넣는 코드 (1단계에서 사용) |
| `index.html` | **학생 신청 화면**. 이 주소를 카톡방에 공유합니다 |
| `admin.html` | **선생님 관리자 화면**. 활동 등록·현황·출석·엑셀 |
| `config.js` | **서버 주소를 적어두는 파일**. 업데이트할 때 이 파일만 덮어쓰지 마세요 |
| `manifest.json`, `manifest-admin.json`, `sw.js`, `icons/` | PWA(홈 화면 앱 설치)용 파일 — 학생용·관리자용 각각 설치됩니다 |

## 1단계 — 서버 만들기 (최초 1회, 약 5분)

> 이 단계만 끝나면 다음부터는 손댈 일이 없습니다.

### ① 스프레드시트 만들기

1. [sheets.new](https://sheets.new) 접속 → 새 스프레드시트가 열립니다.
2. 왼쪽 위 제목을 **`봉사활동 신청 데이터`** 로 바꿉니다.

### ② 코드 붙여넣기

3. 상단 메뉴에서 **확장 프로그램 → Apps Script** 클릭.
4. 새 탭에 열린 편집기에서 기존 내용(`function myFunction() {}`)을 **전부 지웁니다.**
5. 이 폴더의 **`Code.gs` 파일을 메모장으로 열어 전체 복사** → 편집기에 붙여넣기.
6. 💾 저장(Ctrl+S).

### ③ 시트 4개 만들기

7. 편집기 위쪽 함수 선택창에서 **`초기설정`** 을 고르고 **▶ 실행**.
8. 처음 실행하면 권한 요청이 뜹니다:
   - **권한 검토** → 본인 구글 계정 선택
   - "Google에서 확인하지 않은 앱입니다" → **고급** → **(프로젝트 이름)(으)로 이동** → **허용**
   - ※ 선생님이 직접 만든 코드라 뜨는 안내입니다. 정상입니다.
9. 스프레드시트 탭으로 돌아가면 **설정 / 활동목록 / 신청내역 / 출석** 4개 시트가 생겨 있습니다.
10. **[설정] 시트에서 `관리자비밀번호`를 꼭 바꿔주세요.** (기본값 `1234`)

### ④ 웹앱으로 배포 — ⚠️ 가장 중요

11. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**.
12. 톱니바퀴 ⚙️ → **웹 앱** 선택.
13. 아래처럼 설정합니다:

    | 항목 | 값 |
    |------|-----|
    | 설명 | 봉사활동신청 v1 |
    | 다음 사용자로 실행 | **나(본인 계정)** |
    | 액세스 권한이 있는 사용자 | **모든 사용자** ← 반드시! |

    > `모든 사용자`가 아니면 학생들이 로그인 없이 신청할 수 없습니다.

14. **배포** 클릭 → **웹 앱 URL**이 나옵니다.
    `https://script.google.com/macros/s/AKfyc....../exec`
15. 이 주소를 **복사**합니다. (2단계에서 씁니다)

## 2단계 — 주소 넣고 GitHub에 올리기

### ① 주소 붙여넣기 — **config.js 한 파일만**

`config.js` 를 메모장으로 열면 이런 줄이 있습니다.

```js
var BONGSA_API = "";
```

따옴표 사이에 1단계에서 복사한 주소를 넣습니다.

```js
var BONGSA_API = "https://script.google.com/macros/s/AKfyc....../exec";
```

> 따옴표 `" "` 안에만 붙여넣고, 세미콜론 `;` 은 지우지 마세요.

**index.html 과 admin.html 은 손대지 않습니다.**
주소가 config.js 한 곳에만 있어서, 나중에 프로그램을 업데이트할 때
`config.js` 만 그대로 두면 주소를 다시 넣을 필요가 없습니다.

### ② GitHub에 업로드

1. GitHub 저장소에 이 폴더의 파일을 **전부** 올립니다.
   (`index.html`, `admin.html`, `config.js`, `manifest.json`, `manifest-admin.json`, `sw.js`, `icons/` 폴더)
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**
3. 잠시 뒤 주소가 나옵니다.
   - 학생용 : `https://아이디.github.io/저장소명/`
   - 선생님용 : `https://아이디.github.io/저장소명/admin.html`

## 3단계 — 매달 사용법

### 선생님 (활동 등록)

1. `admin.html` 접속 → 비밀번호 입력
2. **[활동 관리]** 탭에서 `＋ 활동 추가`
   - 날짜 / 활동명 / 시작·종료 시간 / 모이는 장소 / 상점 / 정원 / 안내
   - 요일이 2일이면 첫날 활동을 다 넣은 뒤 **`📅 다른 날짜로 복사`** 로 둘째 날을 한 번에 만듭니다
3. **저장하기** → 학생 화면에 즉시 반영
4. **[설정·백업]** 탭에서 회차명(예: 9월 봉사활동)·안내문·신청 마감 시각 설정
5. **[활동 관리]** 탭 아래 **학생 신청 링크 → 주소 복사** → 카톡방에 붙여넣기

### 학생 (신청)

카톡 링크 열기 → 기숙사 → 학번·이름 → 날짜 → 활동 → 확인 체크 → **신청하기**
완료 화면을 캡처하거나 저장·공유할 수 있고, 마감 전까지 본인이 취소할 수 있습니다.

### 선생님 (당일 출석)

1. **[신청 현황]** 탭 — 활동별 신청자 확인 / `엑셀 내려받기` / `명단 복사`(카톡 보고용)
2. **[출석 체크]** 탭 — 활동 선택 → 참석·지각·불참 터치 → **출석 저장**
   - `A4 인쇄` : 서명란이 있는 종이 출석부
   - `엑셀 내려받기` : 활동별 시트로 저장

### 다음 달 준비

1. **[설정·백업] → 💾 백업 파일 저장** (꼭 먼저!)
2. **🗑 신청내역 · 출석 기록 비우기**
3. **[활동 관리]** 에서 날짜·활동만 새로 바꿔 저장

## ❓ 자주 겪는 문제

| 증상 | 해결 |
|------|------|
| 학생 화면이 "서버 주소 설정이 필요합니다" | `config.js` 의 `BONGSA_API` 가 비어 있습니다. 2단계 ①을 다시 확인 |
| 업데이트 후 주소를 다시 물어봄 | `config.js` 를 빈 파일로 덮어쓴 것입니다. 주소를 다시 넣어 올리세요 |
| "서버 응답이 없습니다" | 배포 시 **액세스 권한 = 모든 사용자** 인지 확인. 아니면 배포 → 배포 관리 → 수정 |
| 코드를 고쳤는데 반영이 안 됨 | Apps Script **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**. 주소는 그대로 유지됩니다 |
| 화면이 옛날 그대로 | `sw.js` 첫 줄 `bongsa-v3` 의 숫자를 하나 올려 다시 업로드 |
| 정원 없이 받고 싶음 | 활동 관리에서 **정원 칸을 비워두면** 무제한 |
| 신청을 즉시 막고 싶음 | [설정·백업] → 접수 상태 → **닫힘** → 저장 |
| 학생이 취소를 못 함 | 마감 시각이 지나면 학생 취소가 막힙니다. 선생님이 [신청 현황]에서 이름을 눌러 취소 |

## 🔒 알아두면 좋은 것

- 학생은 **로그인 없이** 신청합니다. 학번·이름만으로 본인을 구분하므로, 같은 학번 중복 신청과 이름 불일치는 시스템이 막아줍니다.
- 관리자 비밀번호는 [설정] 시트에 있습니다. `admin.html` 주소를 학생에게 알려주지 마세요.
- 모든 신청은 **스프레드시트 [신청내역] 시트**에 그대로 쌓입니다. 시스템에 문제가 생겨도 데이터는 구글에 남아 있습니다.
- 취소된 신청은 지워지지 않고 **상태 = 취소**로 남습니다. (기록 보존)
- 스프레드시트 자체도 `파일 → 버전 기록`으로 되돌릴 수 있습니다.

갤럭시 탭 크롬에서 관리자 주소 접속 → 우측 상단 ⋮ → **홈 화면에 추가 / 설치 및 바로가기 만들기**
→ 창이 뜨면 **「설치」**를 고르세요. (「바로가기」는 주소창이 그대로 보입니다.)

'설치'가 안 보이면 `manifest-admin.json` 과 `icons/` 폴더가 GitHub에 올라갔는지 확인하세요.
학생 화면과 관리 화면은 각각 별도의 앱으로 설치되며, 아이콘 색으로 구분됩니다.
